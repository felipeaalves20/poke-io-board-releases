# Poke IO Board — Downloads

Gerencie contas do Pokeidle.io em uma janela, com sessões independentes e streams da Twitch por perfil.

## Download para Windows 64 bits

[Ver versões e baixar](https://github.com/felipeaalves20/poke-io-board-releases/releases)

Cada nova versão oferece um **Setup** para instalar e uma versão **Portátil**, que funciona sem instalação. Nenhuma das opções exige Node.js.

O setup permite escolher a pasta, cria atalhos e oferece a opção de iniciar com o Windows. Feche o aplicativo antes de instalar ou atualizar. As contas, preferências e sessões ficam em `%APPDATA%/Poke IO Board/` e são compartilhadas entre a instalação e o portátil.

Na versão instalada, use **Preferências → Atualizações** para verificar, baixar e reiniciar para instalar uma nova versão. No portátil, o botão direciona à página de download. É necessário instalar uma versão que já contenha esse recurso para receber as próximas atualizações pelo app.

Os arquivos `SHA256SUMS.txt` e `release.json` acompanham as versões para conferência dos downloads. O jogo pode solicitar login ou captcha novamente.

Este repositório contém apenas a página de downloads e as distribuições do aplicativo. O repositório de desenvolvimento permanece privado.
